# Ahmed Yasser Abu Alrob · Portfolio

**Live:** https://ahmadrob.github.io/ahmed-abu-alrob/ · **العربية:** https://ahmadrob.github.io/ahmed-abu-alrob/?lang=ar

Personal site of Ahmed Yasser Abu Alrob, PhD researcher in software engineering at KFUPM, working on adaptive, intelligent user interfaces.

A single, dependency-free HTML page in white and crimson with a dark samurai edge:

- **Blade rail and stance wheel** instead of a nav bar: hold anywhere (or press 構) to jump between chapters.
- **Smooth momentum scrolling**, a pinned sideways work gallery, and WebGL project covers.
- **Blood Moon** mode: the page turns blood red, with a Japanese-only soundscape (koto, shakuhachi, taiko) synthesized live with the Web Audio API.
- **English and Arabic**, with full right-to-left mirroring. `?lang=ar` opens the Arabic version.
- A hidden duel. Type `katana`.

Deployed by GitHub Pages from `main` (see `.github/workflows/static.yml`).

Fonts are loaded from Google Fonts.
