# Liquid Monolith CV

A modern, interactive CV website featuring liquid glass aesthetics and scroll-driven animations.

## 🚀 Live Demo

Visit: `https://[your-username].github.io/liquid-monolith-cv`

## ✨ Features

- **Monochrome Minimalist Design** - Clean white background with black accents
- **Liquid Glass UI** - Translucent layers with backdrop blur effects
- **Scroll-Driven Animations** - Content reveals as you explore
- **Interactive Projects** - Click to expand project details
- **Cursor Tracking** - Subtle liquid blob follows mouse movement
- **Fully Responsive** - Optimized for all screen sizes

## 🛠️ Tech Stack

- React 18
- Vanilla CSS (no frameworks)
- Custom animations and interactions
- Google Fonts (Inter & JetBrains Mono)

## 📦 Deployment

This site is deployed using GitHub Pages.

### Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build process required!

## 🎨 Design Philosophy

Inspired by Apple editorial design, Linear's minimalism, and modern AI lab aesthetics. The site treats content as a vertical sculpture - floating glass panes in a white void that reveal themselves through scroll.
