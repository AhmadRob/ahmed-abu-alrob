    EngiTek 2025 · IEEE Xplore · pp. 1–6

    Engineering Sentient UI: Bridging Emotion, Behavior, and Context for Dynamic UI Adaptation

    A. Y. T. Abu Alrob, O. Aburub

    A modular framework that adapts interface components on the device, keeping emotion recognition, behavior tracking, context sensing, adaptation logic and UI integration as separate, swappable parts.

    Read the abstract

    Adaptive user interfaces (AUIs) enhance usability by dynamically responding to users’ emotional states, behaviors, and contextual factors. Existing approaches often rely on cloud services, introducing latency and privacy risks. This paper presents Sentient UI, a modular framework enabling on-device adaptation of interface components through a clear separation of emotion recognition, behavioral tracking, contextual sensing, adaptation logic, and UI integration. A proof-of-concept demonstration validates real-time visual adaptation under simulated emotional conditions, illustrating architectural feasibility without implying production readiness. By emphasizing low-latency response, developer control, and extensibility, Sentient UI provides a structured foundation for integrating multimodal sensing and context-aware adaptation in future implementations. Ongoing work focuses on expanding affective and contextual sensing modules, optimizing on-device inference, and conducting user-centered evaluations to measure impact on usability and engagement.

    EngiTek 2025 · IEEE Xplore · pp. 1–6

    EvalUI: An AI-Driven Framework for Structural Assessment of UI Layouts

    O. Aburub, A. Y. T. Abu Alrob

    A computer-vision framework that judges UI layouts from screenshots alone: component detection, WCAG 2.1 contrast checks, graph-based spatial analysis and saliency heatmaps, with no source code needed.

    Read the abstract

    While modern interfaces change quickly, traditional accessibility evaluation is still limited by its focus on markup-based analysis. This restricts effective assessments to completed visual implementations. EvalUI is a new computer vision framework which allows a thorough UI layout evaluation through visual analysis. The approach combines several new techniques: adaptive thresholding for reliable component detection in different visual conditions, perceptual modeling for WCAG 2.1 compliant contrast assessment, and graph-based spatial analysis that captures both overall layout structures and individual component relationships. The system is gradio-based and uses visual saliency simulation to provide measurable insights into viewing patterns and the effectiveness of visual hierarchy. A thorough evaluation of two different mobile interfaces, a minimalist contact management screen and the information-packed GOV.UK homepage shows consistent performance across design types. The framework delivers detailed visual diagnostics, such as accessibility overlays and saliency heatmaps, along with standard metrics for contrast compliance (AA/AAA), spatial balance, and hierarchy effectiveness. Importantly, EvalUI works without needing source code, special file formats, or training data. This makes it particularly useful during early design stages when accessibility feedback is most needed but often unavailable. The results highlight the system’s ability to reveal subtle yet significant accessibility problems while offering practical suggestions for improving layout, thus connecting aesthetic design with an inclusive user experience and layout design assessment.
